# Reach

This is a hackathon-scale tool, and we have no usage numbers yet, so none are claimed here.

- **Who it is for:** hackers at ETHGlobal Mumbai looking for a teammate in the first hours of the event.
- **How it spreads:** share the link in the hackathon chat. There is no signup, only a wallet, so the cost of trying it is one click.
- **Why posts expire:** a board that cleans itself stays useful for the whole event without a moderator.
- **Possible next steps:** an ENS name instead of the short address, and Swarm for pitch files.
